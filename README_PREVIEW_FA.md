# پیش‌نمایش ویندوزی MD-Gsm — نسخه ۰٫۲٫۱۰

## تغییرات رابط
- نشان MD، نام کامل «نرم‌افزار جامع مدیریت و حسابداری تعمیرگاه موبایل»، نسخه و تاریخ/ساعت شمسی در سمت راست نوار دوم قرار دارند؛ سه اقدام سریع «پذیرش جدید»، «پذیرش همکار» و «ماشین‌حساب» در سمت چپ هستند.
- پنجره در حالت Maximized اجرا می‌شود؛ محتوای داشبورد به‌صورت واکنش‌گرا از بالا، پایین، راست و چپ هر کدام ۱۰٪ از فضای قابل‌استفاده فاصله دارد.
- اندازه قلم‌های صریح رابط نسبت به v0.2.5 ده درصد افزایش یافته است.
- تب «تحویل امروز» پیش‌فرض است.
- کل فهرست فیلترشده در ارتفاع جدول قابل مشاهده است؛ اسکرول عمودی داخل DataGrid غیرفعال است، اما اگر داشبورد از ارتفاع نمایشگر بلندتر شود، اسکرول صفحه اصلی می‌ماند.
- ستون مستقل ۳٫۳ پیکسلی در سمت راست هر ردیف رنگ اولویت را نشان می‌دهد: قرمز پررنگ `#E00000` برای فوری، بنفش برای همکار، نارنجی برای موعد امروز، سبز برای موعد فردا/پس‌فردا؛ ردیف تحویل‌شده خنثی است.

## اجرا
در پوشه‌ای که `MDGsm.sln` قرار دارد:

```powershell
.\scripts\Run-Persons-Preview.ps1 -Build
```

برای ساخت نصب‌کننده خودبسنده ویندوز (نیازمند .NET 10 SDK و Inno Setup 6؛ Python برای اجرای برنامه یا نصب‌کننده لازم نیست):

```powershell
.\scripts\Build-Windows-Installer.ps1
```

خروجی مورد انتظار: `artifacts\installer\MD-Gsm-Persons-Preview-Setup-v0.2.10.exe`.

## محدودیت
داده‌های داشبورد ساختگی‌اند. بخش پذیرش و اشخاص هنوز به API یا دیتابیس عملیاتی وصل نیستند. Build/Test WPF، ساخت EXE و بررسی تصویری نسخه ۰٫۲٫۱۰ باید روی Windows انجام شود. G1 قفل باقی می‌ماند.



## تغییرات رابط v0.2.8

- پس‌زمینه داشبورد `#F1F5F9` است. لوگو/نام برنامه در سمت چپ سربرگ و دکمه‌های اقدام در سمت راست قرار دارند.
- نوار رنگی کنار ردیف پذیرش به ۳ پیکسل کاهش یافت.
- سرستون‌ها و متن سلول‌ها هم‌راستا و راست‌چین شدند؛ جدول‌های پذیرش و اشخاص اسکرول داخلی ندارند و ارتفاع آن‌ها با تعداد ردیف‌های قابل‌نمایش تنظیم می‌شود. صفحه کلی داشبورد در صورت نیاز برای نمایش نمودارهای پایین اسکرول می‌شود تا محتوا پنهان نماند.


## تغییرات رابط v0.2.9

- نام و نشان برنامه در سمت راست نوار برند قرار گرفته‌اند؛ سه اقدام سریع پذیرش جدید، پذیرش همکار و ماشین‌حساب در سمت چپ هستند.
- ارتفاع نوار منو از ۳۶ به ۴۲ پیکسل و فاصله عمودی دکمه‌های منو افزایش یافته است.
- نشانگر تحویل از ۳ به ۳٫۳ پیکسل افزایش یافته و رنگ فوری به قرمز پررنگ `#E00000` تغییر کرده است.
- عنوان پنجره، نسخه اسمبلی و نام فایل نصب‌کننده به ۰٫۲٫۹ ارتقا یافته‌اند.
- داده‌ها همچنان ساختگی‌اند و G1 مسدود باقی می‌ماند.


## تغییرات رابط نسخه ۰٫۲٫۱۰

- عنوان ستون مشتری به «مشتری» تغییر کرد؛ کد پذیرش همکار بنفش و پس‌زمینه ردیف همکار بنفش بسیار کم‌رنگ است.
- متن تعداد موارد و توضیح پیش‌نمایش از زیر فهرست پذیرش حذف شد.
- فقط فونت منوهای اصلی کمی بزرگ‌تر شد؛ زیرمنوها تغییری نکردند. نشان MD بزرگ‌تر و بالای نام MD-Gsm قرار گرفته است.
- ساخت و اجرای واقعی WPF و تولید EXE باید روی Windows انجام شود.
