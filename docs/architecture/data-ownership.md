## قواعد تغییر مالکیت

- تغییر مالک، تغییر اساسی معماری است و نیازمند ADR جدید است.
- مصرف‌کننده می‌تواند view یا projection قابل‌بازسازی داشته باشد، اما آن projection مرجع حقیقت مستقل نمی‌شود.
- منو، فرم یا گزارش مالک داده نیست؛ مالک بر اساس معنای تجاری داده مشخص می‌شود.
- هر مدل جدید در بازبینی باید شناسهٔ این فهرست یا درخواست ثبت مفهوم جدید را ارجاع دهد.
