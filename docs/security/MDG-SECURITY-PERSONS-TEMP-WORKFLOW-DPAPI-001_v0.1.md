# Persons Temporary Workflow — Windows DPAPI Key Custody Contract

**تصمیم مالک محصول:** تأییدشده در 2026-11-25  
**دامنه:** فقط کلید رمزنگاری Payload موقت Persons برای AC-37  
**وضعیت:** قرارداد مصوب؛ اجرای فنی و آزمون‌ها هنوز باید اثبات شوند.

## سیاست مصوب
- رمزگذاری Payload با AES-256-GCM و حفاظت کلید با Windows DPAPI در محدوده `DataProtectionScope.LocalMachine`.
- هر نصب Windows یک کلید تصادفی مستقل ۲۵۶ بیتی دارد؛ کلیدها بین نصب‌ها و محیط‌ها مشترک نیستند.
- تولید کلید فقط با عملیات Provisioning صریح و مورد اعتماد Setup مجاز است. API و درخواست عادی نباید کلید مفقود را خودکار ایجاد یا جایگزین کنند.
- فقط Blob محافظت‌شده DPAPI در مسیر اختصاصی ProgramData نگهداری می‌شود. کلید خام هرگز در PostgreSQL، تنظیمات، Git، بسته نصب، Log، Telemetry یا Crash artifact ذخیره نمی‌شود.
- DACL پوشه و فایل باید inheritance را غیرفعال و دسترسی را به SID هویت اجرایی نهایی API و LocalSystem محدود کند. مدیر محلی در مرز اعتماد سیستم باقی می‌ماند؛ DPAPI LocalMachine در برابر مدیر محلی مخرب تضمین نمی‌دهد.
- کلید فقط برای `MD-Gsm/Persons/TemporaryWorkflow` است و با IdentityAccess، Recovery، AuditSecurity/Hash Chain یا امضای اسناد مشترک نیست.
- Provider بافر کلید متعلق به فراخواننده تحویل می‌دهد؛ مصرف‌کننده پس از استفاده آن را صفر می‌کند. بافرهای موقت کلید و Plaintext نیز باید پاک شوند.
- هر Payload نسخه کلید خود را نگه می‌دارد. نسخه قدیمی تا وقتی Payload زنده‌ای به آن وابسته است حفظ می‌شود. بازنشستگی فقط پس از Inventory معتبر و اثبات نبود وابستگی مجاز است.
- کلید مفقود، خراب، غیرقابل دسترس یا با نسخه ناشناخته باعث Fail-Closed می‌شود. ساخت خودکار کلید جایگزین ممنوع است.
- DPAPI LocalMachine به همان ماشین وابسته است، نه Backup قابل انتقال. Restore روی دستگاه دیگر بدون فرایند جداگانه و مصوب بازیابی کلید، Promotion را غیرفعال نگه می‌دارد.

## مرز اعتماد
DPAPI LocalMachine از افشای آفلاین معمولی فایل کلید و کاربران فاقد دسترسی لازم محافظت می‌کند؛ اما در برابر SYSTEM، مدیر محلی قادر به تصاحب مالکیت، فرایند API تسخیرشده یا بدافزار با هویت API محافظت مطلق ندارد. این راهکار HSM سخت‌افزاری نیست. API باید با هویت Windows اختصاصی، غیرتعاملی و کم‌اختیار اجرا شود؛ LocalSystem، حساب Administrator یا حساب تعاملی، شواهد استقرار قابل قبول نیستند.

## چرخه عمر
1. Setup مورد اعتماد، هویت نهایی API را احراز و پوشه را با inheritance خاموش ایجاد می‌کند.
2. Setup با CSPRNG ویندوز ۳۲ بایت تولید، با DPAPI LocalMachine و entropy ثابتِ مختص همین Purpose محافظت و با CreateNew اتمیک ذخیره می‌کند.
3. Setup قابلیت Unprotect، طول ۳۲ بایت و ACL را بررسی می‌کند و فقط Metadata غیرحساس را ثبت می‌کند.
4. API در Startup وجود، خوانایی و قابلیت Unprotect کلید را اعتبارسنجی می‌کند؛ هیچ‌گاه کلید تولید، جایگزین یا Rotate نمی‌کند.
5. Rotation عملیات جداگانه با هم‌زیستی نسخه قدیم و جدید و بررسی وابستگی دیتابیس است؛ Rotation خودکار مجاز نیست.
6. حذف کلید فقط پس از تعیین تکلیف نگهداری و Backup با تصمیم مالک انجام می‌شود.

## کنترل‌های پیاده‌سازی
- Provider فقط روی Windows ثبت شود؛ روی سیستم‌عامل دیگر ثبت نشود.
- مسیر پیکربندی‌شده باید مطلق و محدود به زیرشاخه تأییدشده ProgramData باشد.
- ایجاد فایل با CreateNew؛ وجود فایل قبلی باید خطا دهد، نه overwrite.
- طول دقیق ۳۲ بایت، قالب فایل، نسخه و موفقیت DPAPI بررسی شود.
- DACL محافظت‌شده، بدون inheritance و فقط شامل SID هویت API و LocalSystem باشد.
- هیچ کلید خام/محافظت‌شده، Payload یا پیام استثنای حساس وارد Log نشود.
- ثبت Provider به‌تنهایی Feature را فعال نمی‌کند؛ `Persons:WorkflowPromotionApiEnabled` تا مجوز انتشار مستقل خاموش می‌ماند.
- این تصمیم مجوز Migration واقعی، Grant، Listener، Merge یا G1 نیست.

|---|---|---|
| DPAPI-01 | Provision صریح روی Windows | کلید تصادفی ۳۲ بایتی با LocalMachine محافظت و پس از ذخیره قابل خواندن باشد |
| DPAPI-02 | Provision دوم | بدون تغییر کلید موجود رد شود |

| DPAPI-06 | کاربر عادی | خواندن/نوشتن رد شود |
| DPAPI-07 | ماشین اشتباه/Blob خراب/نسخه اشتباه | بارگذاری کلید Fail-Closed |
| DPAPI-08 | چرخه عمر بافر | بافر کلید پس از AES-GCM صفر شود |
| DPAPI-09 | دستکاری AES-GCM | کلید، Nonce، Tag، AAD یا Ciphertext اشتباه رد شود |
| DPAPI-10 | Rotation | نسخه قدیم تا پایان وابستگی حفظ شود |
| DPAPI-11 | Secret hygiene | هیچ کلید یا Plaintext در Log/Trace/Crash/CI نباشد |
| DPAPI-12 | Restore به ماشین دیگر | بدون بازیابی مصوب، Promotion غیرفعال بماند |
