# گزارش تغییرات و اعتبارسنجی MD-Gsm v0.2.10

## تغییرات ثبت‌شده

- عنوان ستون پذیرش به «مشتری» تغییر یافت.
- کد پذیرش برای نوع مشتری «همکار» به رنگ بنفش `#8B5CF6` نمایش داده می‌شود.
- پس‌زمینه ردیف همکار `#FAF7FF` است؛ رنگ نشانگر کناری اولویت همچنان بر اساس سیاست قبلی مستقل تعیین می‌شود.
- کادر شمارش موارد و جملهٔ توضیحی پیش‌نمایش زیر فهرست پذیرش حذف شد.
- فونت فقط منوهای سطح اول از ۱۱ به ۱۲٫۵ افزایش یافت؛ سبک زیرمنوها دست‌نخورده باقی ماند.
- نشان MD با اندازهٔ بزرگ‌تر بالای عبارت `MD-Gsm` قرار گرفت.

## اعتبارسنجی و محدودیت‌ها

- آزمون‌های ایستای Python و دروازه‌های ایستای ماژول اشخاص باید موفق باشند؛ هیچ اتصال به دادهٔ واقعی اضافه نشده است.
- Build ویندوزی WPF، اجرای بصری واقعی، و تولید نصب‌کننده EXE از محیط لینوکسی فعلی اجرا نشده‌اند؛ پذیرش نهایی به اجرای این مراحل در Windows نیاز دارد.
- `g1Authorized=false` باقی می‌ماند؛ این نسخه مجوز شروع G1 یا فعال‌سازی قابلیت‌های عملیاتی نیست.
