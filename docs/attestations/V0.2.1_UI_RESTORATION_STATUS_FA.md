# گزارش وضعیت v0.2.2 — بازگردانی ظاهر داشبورد و منوها

تاریخ: 2026-10-28

## تغییرهای انجام‌شده

- ترتیب نوارها به مرجع بصری نزدیک شد: نوار منو در بالا و نوار برند/اقدامات سریع زیر آن.
- داشبورد شامل KPIها، تب‌ها و جدول پذیرش، نمودار چندسری، پنل بار کاری تکنسین‌ها و دو پنل آمار مصرف قطعات/انواع تعمیرات مطابق ساختار مرجع شد. فوتر نیز با تم تیره بازسازی شد.
- همه ردیف‌های داشبورد با داده ساختگی و صریحاً نمایشی پر می‌شوند؛ هیچ اتصال داده کسب‌وکاری ندارند.
- منوی سطح بالا فقط روی `MouseEnter` باز می‌شود؛ پنل dropdown بعد از نوار برند/اقدامات سریع در هدر قرار دارد و کل هدر محدوده hover است تا هنگام حرکت موس به زیرمنو بسته نشود. handler کلیک برای باز/بسته‌کردن منوی اصلی وجود ندارد.
- منوها در فضای کاری به تب‌های عمومی تبدیل نمی‌شوند. مقصدهای پیاده‌نشده پیام وضعیت می‌دهند و گزینه ثبت/فهرست اشخاص فقط پیش‌نمایش جداگانه اشخاص را باز می‌کند.
- ظاهر در XAML به‌صورت مستقل پیاده‌سازی شده است؛ فایل HTML مرجع به سورس اجرایی یا وابستگی بسته اضافه نشده است.
- هیچ API اشخاص، جدول تجاری، Migration یا دسترسی به داده واقعی اضافه نشده است. `g1Authorized` قفل باقی می‌ماند.

## محدودیت‌ها و موارد تأییدنشده

- در محیط تولید این بسته، .NET SDK/Windows WPF runtime در دسترس نبود؛ بنابراین Build نهایی WPF و اجرای تست‌های .NET در اینجا اجرا نشده‌اند.
- نصب‌کننده Windows هنوز از این محیط تولید نشده است. باید روی Windows با .NET 10 SDK و Inno Setup 6 اجرا شود:

```powershell
.\scripts\Build-Windows-Installer.ps1
```

- پیش از قبول نسخه، Build، مجموعه تست .NET و اجرای دستی پنجره روی Windows باید موفق باشند. گزارش حاضر ادعای قبولی Build/Runtime ندارد.
- فعال‌سازی واقعی قفل شاخه روی Remote SCM هنوز نیازمند شواهد مستقل است.
