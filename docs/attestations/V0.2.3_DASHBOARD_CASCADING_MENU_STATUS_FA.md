# گزارش وضعیت نسخه ۰٫۲٫۳ — داشبورد مرجع و منوهای آبشاری

تاریخ: ۲۰۲۶-۱۰-۲۸
وضعیت: اصلاح سورس انجام شده؛ تأیید Build و اجرای WPF در Windows همچنان لازم است.

## خواستهٔ رابط

- حفظ ترتیب هدر: منوهای اصلی در ردیف باریک بالا، سپس برند و اقدام‌های سریع.
- جایگزینی رفتار مگا‌منوی تمام‌عرض با پنل سفید باریک، متصل به منوی اصلی زیر نشانگر ماوس.
- بازشدن منوهای سطح بالا با Hover؛ منوی سطح بالا Click-handler یا مسیر ساخت تب ندارد.
- تراز لبهٔ راست پنل اصلی با لبهٔ راست عنوان منو در RTL؛ در صورت نزدیک‌بودن به لبهٔ پنجره، گزینهٔ جایگزین placement اجازه می‌دهد پنل در صفحه بماند.
- بازشدن زیرمنوی گروه در سمت چپ با Hover، مطابق رفتار آبشاری تصویر مرجع.
- گروه «رسیدها» به‌عنوان تنها استثنای فعلی، موارد کوچک خود را مستقیم در پنل اصلی نمایش می‌دهد؛ سایر گروه‌های کاتالوگ پنل فرعی دارند.
- نام و شناسهٔ ۱۱ منوی اصلی و گزینه‌ها از کاتالوگ موجود خوانده می‌شود؛ عناوین جدید جایگزین کاتالوگ نشده‌اند.
- داشبورد شامل چهار کارت KPI، فهرست پذیرش با سه تب، جست‌وجو/فیلتر، ستون وضعیت و عملیات، نمودار روند هفتگی، بار کاری تکنسین‌ها و دو نمودار ستونی گزارش است.

## داده و مرز معماری

تمام ارقام، نام‌ها و تلفن‌های جدول/نمودار دادهٔ ساختگی نمایشی هستند. تلفن‌ها ماسک شده‌اند. تغییرات این نسخه شامل API اشخاص، مدل دادهٔ تجاری Persons، Migration تجاری یا اتصال ذخیره‌سازی عملیاتی نیست. دادهٔ پیش‌نمایش اشخاص فقط در حافظهٔ همان اجرای برنامه می‌ماند. `g1Authorized=false` باقی است.

## بررسی‌های انجام‌شده در محیط آماده‌سازی

- تمام XAMLها و فایل‌های پروژهٔ C# به‌صورت XML parse شدند.
- برای ۱۴ رویداد XAML، متد متناظر در code-behind پیدا شد؛ مورد مفقود پیدا نشد.
- گیت‌های ایستای Persons: موفق.
- آزمون‌های سیاستی fail-closed: ۱۰ موفق، صفر شکست.
- بررسی مرجع منو: ۱۱ منوی اصلی در کاتالوگ وجود دارد.
- بررسی فایل‌های جاری: ارجاع فعال به `MegaMenuPanel` در XAML حذف شده است؛ تست UI به `RootMenuPopup` و `PlacementMode.Left` به‌روزرسانی شده است.

## محدودیت تأیید

در محیط آماده‌سازی حاضر ابزار `dotnet`، Windows PowerShell و Inno Setup موجود نیست؛ بنابراین Build واقعی WPF، اجرای xUnit در بستهٔ ۰٫۲٫۳، اجرای بصری برنامه و ساخت EXE نصب‌کننده در اینجا انجام نشده‌اند. نتایج Build/Test نسخه‌های قبلی به نسخهٔ ۰٫۲٫۳ تعمیم داده نمی‌شوند.

## گام اعتبارسنجی در Windows

از ریشهٔ بسته:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\Validate-Stage9-Baseline.ps1
.\scripts\Run-Persons-Preview.ps1 -Build
```

پس از تأیید Restore/Build/Test و اجرای بصری، برای ساخت نصب‌کننده با .NET 10 SDK و Inno Setup 6:

```powershell
.\scripts\Build-Windows-Installer.ps1
```

این برنامه و ساخت‌کنندهٔ نصب‌کننده به Python وابسته نیستند؛ Python فقط در بعضی گیت‌های توسعهٔ منبع استفاده می‌شود. موفقیت گیت‌های محلی اثبات‌کنندهٔ فعال‌بودن Branch Protection در مخزن Remote نیست. شروع G1 و تغییر دیتابیس همچنان قفل هستند.
