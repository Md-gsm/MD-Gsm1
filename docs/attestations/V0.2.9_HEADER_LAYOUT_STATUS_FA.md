# گزارش تغییرات و اعتبارسنجی MD-Gsm v0.2.9

## تغییرات درخواست‌شده

- بلوک نشان، نام کامل برنامه، نسخه و تاریخ/ساعت زنده به سمت راست فیزیکی نوار برند منتقل شد.
- دکمه‌های «پذیرش جدید»، «پذیرش همکار» و «ماشین‌حساب» به سمت چپ فیزیکی منتقل شدند.
- ارتفاع ردیف ناوبری اصلی از ۳۶ به ۴۲ پیکسل افزایش یافت؛ padding عمودی دکمه‌های سطح اول از ۴ به ۶ پیکسل افزایش یافت.
- عرض خط نشانگر تحویل از ۳ به ۳٫۳ پیکسل افزایش یافت (۱۰٪). قرمز فوری از `#B91C1C` به قرمز اشباع‌تر `#E00000` تغییر کرد. بنفش همکار، نارنجی موعد امروز و سبز موعد فردا/پس‌فردا بدون تغییر هستند.
- شماره نسخه در پنجره، اسمبلی و فایل نصب‌کننده به ۰٫۲٫۹ ارتقا یافت.

## شواهد انجام‌شده در محیط حاضر

- ۲۳ آزمون Python در مجموعه `scripts/ci` موفق شدند.
- دروازه‌های ایستای اشخاص موفق شدند؛ `g1Authorized` همچنان `false` است.
- ۱۱۹ ورودی SHA-256 بازبینی و تأیید شدند.
- فایل‌های XAML/CSProj به‌عنوان XML و فایل‌های JSON با parser بررسی شدند.
- `git diff --check` بدون خطای whitespace انجام شد.

## محدودیت اعتبارسنجی

Build واقعی WPF، اجرای تصویری روی Windows، و کامپایل نصب‌کننده با Inno Setup در این محیط انجام نشده‌اند. این موارد پیش از پذیرش نهایی باید در Windows اجرا شوند. این نسخه فقط تغییر رابط و بسته‌بندی است؛ هیچ API تجاری، جدول اشخاص، Migration یا اتصال داده واقعی اضافه نشده است.
