# گزارش وضعیت MD-Gsm v0.2.5 — خوانایی، فاصله‌بندی و اولویت تحویل

- پایه: Stage9 مستقل MD-Gsm؛ از Stage10 یا سورس اجرایی پروژه قبلی استفاده نشده است.
- شاخه: `fix/readable-dashboard-delivery-markers-v0.2.5`.
- وضعیت: اصلاح سورس و کنترل‌های ایستا آماده؛ Build و اجرای تصویری روی Windows لازم است.

## موارد اصلاح‌شده
1. متن‌های ریز منو/تب/جدول بزرگ‌تر شده‌اند: منوی اصلی ۱۱، منوی آبشاری/دکمه سریع ۱۲، تب ۱۴، سرستون/سلول جدول ۱۳.
2. پنجره Maximized باقی است، ولی داشبورد حاشیه `26,18,26,28` دارد.
3. `تحویل امروز` از ابتدا فعال است.
4. فیلتر تحویل امروز تمام ردیف‌های موعد امروز را به جز «تحویل داده شده» نمایش می‌دهد؛ شمارنده نیز با همین قاعده محاسبه می‌شود.
5. خط ۵ پیکسلی در لبه راست ردیف بر اساس `MarkerBrush` ترسیم می‌شود، نه `Status`: فوری قرمز پررنگ، همکار بنفش، فردا/پس‌فردا سبز، امروز نارنجی. Tooltip دلیل رنگ را بیان می‌کند.
6. داده‌های نمونه تغییر کردند تا ردیف‌های غیر فوری نارنجی، همکار بنفش، موعدهای آینده سبز و مورد فوری قرمز قابل مشاهده باشند.

## آزمون/محدودیت
- تست‌های معماری C# برای حاشیه، تب پیش‌فرض، شرط فیلتر، رنگ‌های نشانگر و مستقل‌بودن رنگ از Status به‌روزرسانی شدند.
- این محیط Windows/WPF runtime در دسترس ندارد؛ Build، تست .NET و مشاهده تصویری واقعی هنوز اجرا نشده‌اند و نتیجه PASS اعلام نمی‌شوند.
- هیچ دیتابیس یا Migration تجاری تغییر نکرده؛ پیش‌نمایش هنوز فقط با داده ساختگی کار می‌کند و `g1Authorized=false` است.
