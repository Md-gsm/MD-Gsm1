# گزارش تغییرات سربرگ MD-Gsm v0.2.7

## درخواست
انتقال لوگو، نام برنامه و تاریخ به محدوده قبلی سه اقدام سریع؛ نمایش نام کامل «نرم‌افزار جامع مدیریت و حسابداری تعمیرگاه موبایل».

## تغییرات
- جابه‌جایی بلوک هویت برنامه به ستون چپ در نوار دوم.
- جابه‌جایی دکمه‌های «پذیرش جدید»، «پذیرش همکار» و «ماشین‌حساب» به ستون راست.
- نگهداری نشان MD، نسخه پیش‌نمایش و ساعت/تاریخ شمسی زنده در بلوک هویت.
- به‌روزرسانی عنوان پنجره و نام برنامه/میانبر نصب‌کننده.
- افزودن آزمون ایستای جلوگیری از بازگشت اشتباه جایگاه گروه‌ها.

## اعتبارسنجی این بسته
- ۱۷ آزمون منبعی/سیاستی Python موفق؛ صفر شکست.
- همه فایل‌های XAML، پروژه، props و targets از نظر XML معتبر؛ همه JSONها معتبر.
- ۱۱۶ ورودی SHA-256 پس از نهایی‌سازی Manifest بررسی شدند.
- فایل XAML به‌صورت XML اعتبارسنجی می‌شود.
- این محیط Build واقعی WPF ویندوز یا ساخت EXE را انجام نمی‌دهد؛ این دو کنترل روی ویندوز همچنان لازم‌اند.
- هیچ جدول تجاری، Migration، API عملیاتی یا داده پایدار اشخاص اضافه نشده است. مجوز G1 تغییری نمی‌کند.
