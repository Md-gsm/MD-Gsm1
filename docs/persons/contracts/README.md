# قراردادهای ماژول اشخاص — نقطه شروع طراحی G1

این پوشه فعلاً قالب/مرز است؛ هیچ endpoint یا قرارداد منتشرشده‌ای را ادعا نمی‌کند.

پیش از افزودن route یا DTO اجرایی باید قرارداد API نسخه‌دار و بازبینی‌شده افزوده شود. حداقل دامنه طراحی برای بازبینی:

- ایجاد و بازیابی شخص با شناسه پایدار؛
- ویرایش مشروط به نسخه رکورد برای کنترل تعارض؛
- جست‌وجوی مجاز و بدون افشای وجود اشخاص خارج از Scope؛
- عملیات تماس و نشانی با تاریخ اعتبار و وضعیت‌های جدا؛
- پرونده‌های تکراری و تصمیم بررسی؛
- داده موقت گردش‌کار با TTL و تبدیل کنترل‌شده؛
- پیش‌نمایش و اجرای ادغام فقط بعد از کامل بودن قرارداد تمام مشارکت‌کنندگان؛
- پاسخ خطای یکسان/کم‌افشا برای موارد ممنوع طبق ماتریس امنیت؛
- شناسه درخواست/ممیزی بدون PII در log.

قرارداد نهایی باید در آزمون مصرف‌کننده و `persons-api-contract` کنترل شود. نبود فایل در این مرحله عمدی است و CI فقط به‌دلیل نبود runtime اثبات‌شده `PASS-N/A` می‌دهد.
