- migration و schema تجاری Persons: پیاده‌سازی نشده
- داده موقت، worker، merge execution و امنیت Runtime: پیاده‌سازی نشده‌اند.

## اولین برش اجرایی
در شاخه `implementation/g1-persons-partyid-domain`:
- پروژه مستقل `MDGsm.Persons.Domain` ایجاد شد.
- نوع مقدار `PartyId` به‌صورت opaque و مبتنی بر UUIDv7 پیاده‌سازی شد.
- ساخت و parsing شناسه، version UUIDv7 و RFC variant را اعتبارسنجی می‌کند؛ Parse/TryParse فقط lowercase canonical UUID در قالب `D` را می‌پذیرند.
- `Guid.Empty` و قالب‌های `N`/`B`/`P` و حروف بزرگ رد می‌شوند.
- تست واحد برای تولید، رد version/variant نامعتبر، Empty، قالب‌های غیرcanonical با GUID ثابت، رد null و ورودی فاصله‌دار، یکتایی تولید هم‌زمان ۴۰۹۶ شناسه و round-trip اضافه شد. تست وابسته به ساعت واقعی و انتظار ۳ ثانیه‌ای حذف شد تا روی runner شلوغ ناپایدار نباشد.
- آزمون معماری C# وجود پروژه Persons Domain در Solution، TargetFramework=net10.0 و نبود ProjectReference، PackageReference و FrameworkReference را کنترل می‌کند؛ گیت Python نیز همین محدودیت وابستگی را بررسی می‌کند.
- پروژه به Solution و تست‌های Domain متصل شد.

هیچ Party aggregate، profile حقیقی/حقوقی، تماس، نرمال‌سازی موبایل، نقش، endpoint، جدول، migration، DbContext، worker یا UI ساخته نشده است. این موارد در برش‌های بعدی و با آزمون‌های مستقل اجرا می‌شوند. شناسه رسمی، شناسه مالیاتی و هر داده‌ای که ADR-0008/key management لازم دارد همچنان ممنوع است.

- ADR-0007، ADR-0009 و ADR-0010 همچنان Proposed هستند؛ شروع این برش به دستور مالک انجام شده، نه به‌عنوان تصویب این ADRها یا مجوز فعال‌سازی G1.
- گروه مشاور هنوز باید SHA نهایی کد و طراحی هم‌تراز را بررسی کند. PR #12 به‌صورت stacked روی PR #11 باقی می‌ماند و تا ثبت نتیجه بازبینی گروه مشاور merge نمی‌شود.
- اگر بازبینی، محل PartyId، قرارداد canonical یا مرز Domain را تغییر دهد، این برش و تست‌هایش باید بازنگری شوند. این ریسک بازکاری آشکارا ثبت شده و هیچ تأیید قبلی برای کد فعلی فرض نمی‌شود.
این برش فقط زمانی قابل قبول است که CI ویندوزی روی .NET 10 build و unit tests را با موفقیت اجرا کند و بازبینی معماری/امنیت مربوط به تغییرات انجام شود. قبولی این برش هیچ AC دیگری را خودکار PASS نمی‌کند. AC-50..AC-73 و AC-31..AC-45 فقط با شواهد مستقل از UNMAPPED خارج می‌شوند.
