## شواهد و مرزبندی

- انتصاب اعضای گروه مشاور نرم‌افزار برای هر مرحله توسط مالک پروژه اعلام می‌شود و نیازمند فهرست اسامی ثابت در این مخزن نیست.
- نام دقیق jobها در workflow ثبت شده‌اند؛ Required بودن آن‌ها باید جداگانه از تنظیمات SCM اثبات شود.
- PR آزمایشی شماره ۶ با وابستگی معماری ممنوع، check معماری را شکست داد و GitHub وضعیت آن را `blocked` گزارش کرد.
- مقدار `requiredStatusChecksConfiguredInScm` تا زمان مشاهدهٔ تنظیمات دقیق remote همچنان `false` می‌ماند.
- هر تغییر در job، نام check یا شرط اجرا نیازمند بازبینی و آزمون enforcement است.
