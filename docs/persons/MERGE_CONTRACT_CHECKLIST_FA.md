# چک‌لیست کامل‌بودن قرارداد ادغام اشخاص

**حالت:** معیار طراحی/چک‌لیست توسط مالک پروژه در گفت‌وگوی پروژه مورخ ۲۰۲۶-۱۰-۲۹ پذیرفته شده است؛ اجرای واقعی ادغام در این بسته وجود ندارد.

## چک‌لیست اجباری برای هر مصرف‌کننده

- [ ] مصرف‌کننده در `consumer-registry.json` با شناسه و نسخه قرارداد ثبت شده است.
- [ ] همه ارجاع‌ها در FK، ORM، API، event/message، job، projection، import/export و داده قابل‌بازسازی کشف شده‌اند.
- [ ] هر ارجاع دقیقاً یک طبقه دارد: انتقال فعال، حفظ تاریخی، مانع ادغام یا داده مشتق قابل‌بازسازی.
- [ ] قرارداد شامل `Prepare`, `Validate`, `Apply`, `Verify`, `Recovery/Retry` است.
- [ ] رفتار تعارض، برنده/حفظ/توقف و مجوز لازم صریح است؛ overwrite ضمنی وجود ندارد.
- [ ] پیش‌نمایش فقط‌خواندنی است و شمار ارجاع‌ها و تعارض‌ها را با رعایت Scope/Mask نشان می‌دهد.
- [ ] قرارداد idempotency و برخورد با کلید تکراری دارای payload متفاوت آزموده شده است.
- [ ] تست هم‌زمانی، چرخه ارجاع و قفل‌گذاری با ترتیب ثابت وجود دارد.
- [ ] برای هر مرز Apply، failure injection و اثبات rollback/بازیابی وجود دارد.
- [ ] snapshot اسناد تاریخی بدون تغییر باقی می‌ماند و تعداد ارجاع‌های فعال با نتیجه نهایی تطبیق می‌کند.

## دروازه کمی سامانه

| شاخص | حد پذیرش |
|---|---:|
| ارجاع‌های کشف‌شده و ثبت‌شده | ۱۰۰٪ |
| ارجاع ناشناخته | ۰ |
| ارجاع بدون طبقه یا چندطبقه متناقض | ۰ |
| قرارداد ناقص مشارکت‌کننده | ۰ |
| تعارض مسدودکننده حل‌نشده هنگام اجرا | ۰ |
| آزمون قراردادی اجباری موفق | ۱۰۰٪ |
| وضعیت نیمه‌ادغام‌شده پس از شکست | ۰ |
| تغییر محتوایی snapshot تاریخی بر اثر ادغام | ۰ |

`MergeContractComplete=true` فقط وقتی مجاز است که پوشش و تست‌ها کامل باشند. `MergeAllowed=true` علاوه بر آن به صفر بودن تعارض مسدودکننده نیاز دارد. `SKIP`, مقدار نامشخص یا `N/A` بدون اثبات ماشینی به‌منزله FAIL است.

## سیاست تصحیح/بازگشت

Undo عمومی و خودکار وجود ندارد. هر برگشت کنترل‌شده نیازمند اثبات این است که بعد از ادغام اثر وابسته جدیدی ایجاد نشده و تمام مشارکت‌کنندگان برگشت امن را پشتیبانی می‌کنند. در غیر این صورت اصلاح ممیزی‌شده انجام می‌شود.

## سابقه تصویب

مالک پروژه، این چک‌لیست را به‌عنوان معیار اجباری طراحی و پذیرش ادغام در گفت‌وگوی پروژه مورخ ۲۰۲۶-۱۰-۲۹ پذیرفته است. این تصویب، اجرای ادغام یا کامل‌بودن تست‌های AC-39 تا AC-45 را تأیید نمی‌کند.
