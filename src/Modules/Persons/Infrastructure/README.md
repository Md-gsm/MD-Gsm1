# Persons Infrastructure — module-owned target location

This is the approved module-owned target location for Persons infrastructure. Current PostgreSQL persistence remains in the transitional BuildingBlocks placement documented by ADR-0014. Persons migration(s) are owned by the application migration runner and have been validated only against disposable PostgreSQL 18 databases.

This directory being reserved does not mean that no Persons persistence exists. Avoid duplicate repositories or migrations during future relocation. G1 remains unauthorized.
